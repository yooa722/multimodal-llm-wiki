# 多模态 LLM Wiki Purpose

## 目标

把经过授权的文档持续编译为可浏览、可链接、可追溯、可增量维护的知识页，并支持基于原始 Evidence 的图文问答。

## 核心边界

- 文本 LLM Wiki 是唯一知识主干；多模态能力只能作为同一页面体系上的增量表示层。
- Wiki 页面负责组织长期知识，原始 Evidence 负责证明事实，检索与模型负责定位和解释。
- 不为每个 Chunk 建知识页，不把向量索引当作 Wiki，也不把 Caption 当作原图。
- 查询只读取 Wiki 和 Evidence，不自动修改稳定知识页。

## 目标读者

- 需要浏览知识结构、核验来源和查看原图/完整表格的研究人员。
- 通过 OpenCode Skill 构建、查询和维护 Wiki 的智能体。

## 成功标准

- 新来源能够更新已有概念、实体和分析页，而不是不断生成孤立摘要。
- 每个稳定结论都能回到 `source_id + source_version + item_id`。
- 多模态阶段复用文本 Wiki 和文本向量，只增加必要的表格、公式、原图及受影响页面更新。
- Evidence 不足、来源冲突或图像不可辨认时明确拒答或标记不确定。
