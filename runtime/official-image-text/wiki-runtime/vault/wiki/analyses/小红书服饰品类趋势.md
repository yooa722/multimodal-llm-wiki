# 小红书服饰品类趋势

**小红书服饰品类趋势**基于2024年618期间的大盘数据，分析了女装、内衣、饰品、男装、箱包、运动户外及童装等细分品类的增长热点和消费者偏好 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0016-b0001]。

### 女装
- **高增品类**：度假风连衣裙、舒适休闲T恤及垂感慵懒休闲裤增速高 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0017-b0001]。
- **持续热点**：背心吊带在今年春季及去年618期间均有较强增幅 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0019-b0001]。

### 内衣
- **夏季热点**：运动/无痕文胸、超薄无痕塑身夏季增速高 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0021-b0003]。
- **需求旺盛**：可外穿家居服需求旺盛 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0021-b0001]。
- **潜力SPU**：蕉内、爱慕、六只兔子、伊维斯等品牌的蕾丝文胸在潜力SPU榜单中排名上升 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0021-b0006]。

### 饰品
- **夏季需求**：度假风项链/手链/串珠夏季需求旺盛，贝壳GMV增长84%，度假风项链GMV增长326% ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0023-b0001]。
- **美好寓意**：四叶草/葫芦等美好寓意吊坠高热不减 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0025-b0002]。
- **材质趋势**：宽版冰透翡翠饰品、白玉平安扣及藕粉手串增速高；水晶中石榴石、紫水晶、黄水晶更受青睐 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0025-b0001]。

### 男装
- **夏季热点**：透气宽松短袖及套装短裤在夏季增速高 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0027-b0001]。
- **风格需求**：同时存在商务/修身Polo需求，轻熟风GMV增长219% ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0027-b0014]。

### 箱包
- **夏季热点**：大容量卡通/丹宁包夏季增速高 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0029-b0002]。
- **材质款式**：银色/草编材质应季牛角/新月款式猛增，银色包袋GMV增长231% ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0031-b0001]。

### 运动户外
- **功能需求**：速干/透气/凉感/轻薄是夏季主要需求 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0048-b0044]。
- **鞋履热点**：德训鞋在夏季需求度高，厚底/红色/做旧款受欢迎 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0048-b0049]。

### 童装
- **面料偏好**：舒适的纯棉/吸汗面料是给孩子的最优选择 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0048-b0054]。
- **功能重视**：儿童户外服选择更重视防晒的功能性 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0048-b0058]。
