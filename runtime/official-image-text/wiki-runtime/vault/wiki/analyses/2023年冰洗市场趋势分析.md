# 2023年冰洗市场趋势分析

本页面汇总了[[奥维云网]]发布的关于2023年开年[[冰洗市场]]的表现小结及未来促销期预测。

## 1. Q1 市场回顾：需求释放不及预期

2023年第一季度，冰洗市场需求释放不及预期，整体增长乏力 ^[extracted]。与此同时，对比2022年第四季度，2023年初上游原材料成本压力开始显现：美原油指数在2022年中达到峰值后持续下行，至2023年4月初处于低位区间波动 ^[extracted]；钢铁指数在2022年3月底达峰后大幅下跌，于2022年8月触底，2023年初小幅回升 ^[extracted]。成本压力的变化迫使企业在“聚焦利润”与“聚焦规模”之间做出战略抉择 ^[extracted]。

### 线上价格战苗头
线上市场均价同比出现下滑，显示出价格竞争的迹象：
- **洗衣机**：2023年第1-13周，线上10Kg洗衣机各价格段均价同比降幅在 4.5% 至 7.6% 之间 ^[extracted]。其中2-2.5K与3.5-4K价位占比显著提升 ^[extracted]。
- **冰箱**：2023年第1-13周，线上冰箱各价格段均价同比降幅在 2.4% 至 8.2% 之间 ^[extracted]。对开门、三门、十字4门的中高端份额上升 ^[extracted]。
- **细分品类价格同比**：2023M01-13线上冰洗细分品类价格同比整体呈下降趋势，如三门冰箱-8.2%，滚筒洗衣机-5.14%，干衣机整体-19.49% ^[extracted]。

## 2. 线下市场：高端化趋势延续

尽管线上价格承压，线下市场仍呈现高端化趋势。中国财富家庭规模数据显示，拥有净资产达600万人民币的富裕家庭数量为5,076,600户，相比2020年增长1.33%，超高端人群基数的增加支撑了这一趋势 ^[extracted]。

- **洗衣机**：2023年线下滚筒洗衣机价格结构中，5-6K与6-7K价位占比高于2022年；滚筒烘干机中4.5-5K与8-10K占比提升 ^[extracted]。
- **冰箱**：2023年线下冰箱价格结构中，法式多门、十字4门、对开门的中高端价位（4-8K、8-15K、15K+）份额普遍高于2022年 ^[extracted]。

### 产品关键词
2023年冰洗产品的三大关键词为：
1. **[[薄嵌产品]]**：2023M01-13线上冰洗薄嵌产品零售额规模同比增长，其中平嵌冰箱同比增长2886%，零嵌冰箱同比增长125.2%，超薄洗衣机同比增长19.1% ^[extracted]。
2. **[[大容量产品]]**：2023M01-13线上600L+冰箱销额占比24.5%（同比+36%），10kg+洗衣机销额占比7.3%（同比+1.3%） ^[extracted]。
3. **[[白色家电产品]]**：2023M01-13白色冰箱线上销额9.6亿元（同比+54.2%），线下销额3.2亿元（同比+46.6%） ^[extracted]。
