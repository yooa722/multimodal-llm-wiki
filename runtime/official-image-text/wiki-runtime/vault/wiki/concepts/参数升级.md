# 参数升级

**参数升级**是指厨卫产品通过提升核心性能指标（如油烟机的风量、热水器的容积/升数、燃气灶的热效率等）来增强产品竞争力，并以此支撑价格升级、推动行业摆脱“高配低价”竞争泥沼的发展趋势。

在2023年618期间，参数升级主要表现为：

1.  **环保与能效**：在理性消费力驱动下，环保理念渐成共识 ^[extracted]。高热效率燃气灶（热效率＞63%）和冷凝式燃气热水器等节能产品的销额占比显著提升，推动了产业升级 ^[inferred]。
    *   **冷凝式燃气热水器**：线上销额占比从2019年的0.6%持续上升至2023年618的6.9%，显示节能型热水器市场渗透率稳步提高 ^[extracted]。
    *   **高热效率燃气灶**：线上热效率大于63%的产品销额占比从2019年的11%大幅攀升至2023年618的36%，表明高效能灶具已成为市场主流选择之一 ^[extracted]。
2.  **性能强化**：油烟机大风量段、电热水器大容积段、燃气热水器大升数段的产品均价高于品类平均水平，且市场份额稳步增长，表明消费者愿意为更高的性能参数支付溢价 ^[inferred]。

参数升级与[[形态升级]]相辅相成，共同推动了厨卫刚需品类的高端化发展。
