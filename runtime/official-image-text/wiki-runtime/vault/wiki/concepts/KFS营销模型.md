# KFS营销模型

**KFS营销模型**是小红书推出的一种产品种草组合投放方式，包含KOL内容合作（Key Opinion Leader）、信息流广告（Feeds）和搜索广告（Search） ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0007-b0012]。该模型旨在帮助品牌高效种草，充分发挥内容与流量效能，影响用户站内决策全流程 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0007-b0020]。

### 核心组成

*   **KOL（内容制造）**：通过[[蒲公英]]平台进行优质内容产出，利用达人影响力进行种草 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0007-b0023]。
*   **Feeds（信息流）**：通过定向曝光潜力笔记，大流量种草目标人群，解决自然流量生命周期短的问题 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0007-b0035]。
*   **Search（搜索）**：在搜索爆发高峰期定向引流，承接即时需求，完成转化 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0007-b0035]。

### 与用户路径的映射

根据用户消费路径分型，KFS模型各要素可映射至不同阶段 ^[20230507-小红书-服饰潮流行业-好产品赢战618@7943c2dd3155#item-p0006-b0001]：
- **Feel（感知/探索）**：对应**探索型用户路径**。用户在浏览阶段产生灵感与需求，品牌通过KOL内容和信息流广告激发兴趣。
- **Shop（决策/购买）**：对应**决策型用户路径**。用户在搜索阶段进行深度决策，品牌通过搜索广告承接精准需求，促进转化。

### 营销价值

*   **成本优化**：广告投放帮助内容通过更低分发成本获得更大流量 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0007-b0012]。
*   **流量可控**：弥补笔记自然生命周期有限且难以把控的缺点，通过加投广告流量让好内容精准触达用户 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0007-b0020]。
*   **人群确定**：通过人群定向进行投流，快速扩充目标受众，测出优质笔记并放量 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0007-b0023]。

### 服饰行业618 KFS配比建议

在2024年618大促中，小红书服饰行业根据不同营销阶段调整KFS比例，以优化投放效果 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0007-b0019]：

*   **蓄水期（5.1-5.17）**：KFS比例为 **3:5:2**。此阶段侧重内容占位和前期蓄水，KOL内容占比相对较高 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0007-b0019]。
*   **爆发期（5.31-6.18）**：KFS比例为 **1:7:2**。此阶段侧重集中转化，大幅增加信息流广告（Feeds）占比以获取最大流量 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0007-b0019]。
*   **返场期（6.19-6.30）**：KFS比例为 **2:5:3**。此阶段侧重长效经营和出游季布局，搜索广告（Search）占比略有提升 ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0007-b0019]。

### 2024年618趋势与KFS应用
2024年618期间，小红书服饰行业涌现出多个高热风格标签，如“夏日少女感”（搜索量160w+）、“户外山系风”（搜索同比+78%）和“海岛度假风”（浏览量1.7亿） ^[服饰潮流行业-闭环全攻略@e471f79c739e#item-p0004-b0006]。这些高搜索量和浏览量的数据表明，在618前期种草阶段，内容（K）与搜索（S）之间存在强关联。品牌可通过KOL内容激发用户对特定风格的兴趣，进而引导用户通过搜索行为收敛心智，最终通过信息流广告（F）实现高效转化。
