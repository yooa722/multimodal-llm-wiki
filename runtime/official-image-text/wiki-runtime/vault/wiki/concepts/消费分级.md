# 消费分级

**消费分级**是2023年抖音618好物节期间呈现出的核心市场特征，表现为“理性回归”下的价格带两极分化 ^[extracted]。

## 核心表现

*   **价格带分化**：商品销售额中，100-300元区间规模最大，满足大众日常需求；而1000元以上的高奢价格带销售额同比增长最为显著 ^[extracted]。
*   **销量分布**：在销量层面，10元以下价格带规模最大，同时1000元以上价格带的销量规模也实现了显著同比增长 ^[extracted]。
*   **品类差异**：不同品类表现出不同的分级趋势。例如在美妆领域，面部护肤市场稳定，但高奢消费价格增长显著 ^[extracted]；在运动户外领域，80-100元以下及1000元以上价格带增长显著 ^[extracted]。

## 典型品牌案例

高客单价品牌在618期间的强劲表现进一步印证了高端消费端的增长潜力：
*   **[[海尔]]**：大家电代表，销售额同比增长141.55%，通过专业自播矩阵支撑高客单决策 ^[extracted]。
*   **[[雅萌]]**：美容仪器代表，销售额同比增长118.92，依靠头部KOL带货推动高单价SKU（如售价¥5799的MAX二代）进入销量TOP10 ^[extracted]。
*   **[[蕉下]]**：户外服饰代表，销售额同比增长648.78%，通过搜索优化与货架场经营实现爆发 ^[extracted]。

## 驱动因素

这种分级现象反映了消费者在促销节点更加理性，一方面追求极致性价比（低价走量），另一方面愿意为高品质、高品牌溢价的奢侈品或高端产品买单（高客单增长） ^[inferred]。中间价位段的增长相对平缓或受到挤压。
