# 冰洗市场

**冰洗市场**是指冰箱（Refrigerator）和洗衣机（Washing Machine）组成的家电细分市场 ^[extracted]。该市场受宏观经济、原材料成本、消费者偏好及促销活动影响显著。

### 市场特征
- **季节性波动**：市场需求在五一、618等促销节点集中释放 ^[extracted]。
- **渠道分化**：线上市场倾向于价格竞争，2023年初均价同比下滑显示价格战苗头 ^[extracted]；线下市场则延续高端化趋势，超高端人群基数增加支撑了这一趋势 ^[extracted]。
- **产品趋势**：2023年，[[薄嵌产品]]、[[大容量产品]]和[[白色家电产品]]成为市场关注的关键词，零售额份额呈同比上升态势 ^[extracted]。
