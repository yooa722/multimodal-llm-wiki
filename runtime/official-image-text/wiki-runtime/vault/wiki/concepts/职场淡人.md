# 职场淡人

**职场淡人**是2024年成为职场最佳人设的一种生活态度。其特征表现为“目标淡淡的，情绪淡淡的”，追求在忙碌工作中找回柔软自在的状态 ^[extracted]。

### 社会热度
- **话题数据**：#淡人 话题在小红书拥有4300万+阅读量，#职场淡人 拥有75万+阅读量，#正式确诊为职场淡人 拥有20万+阅读量 ^[extracted]。
- **衍生话题**：#淡人vs浓人（2700万+阅读量）、#人生是巨大的由浓变淡（1800万+阅读量） ^[extracted]。

### 消费特征
- **人群画像**：45%的Z世代追求高效的工作方式 ^[extracted]。
- **品牌偏好**：64%的消费者选择国产品牌 ^[extracted]。
- **关注点**：重视产品的功能性与实用性，消费前会主动搜索相关信息 ^[extracted]。
- **趋势好物**：关联消费品类包括湿厕纸（如舒洁山茶花湿厕纸）、键鼠套装、无线蓝牙耳机等提升办公舒适度和效率的产品 ^[extracted]。
