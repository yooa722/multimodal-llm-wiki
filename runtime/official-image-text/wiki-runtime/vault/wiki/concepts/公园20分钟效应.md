# 公园20分钟效应

**公园20分钟效应**是2024年风靡全网的轻户外生活方式潮流。该理论主张在公园待20分钟，通过晒太阳和接触自然获得“精神的光合作用”，从而实现休息与恢复 ^[extracted]。

### 数据表现
- **热度**：在小红书平台，#公园20分钟效应 话题拥有8000万+阅读量，3.5万+用户参与；#20分钟公园理论 拥有3000万+阅读量 ^[extracted]。
- **参与度**：小红书中38%的用户主动参与轻户外活动 ^[extracted]。
- **人群特征**：Z世代（00后、95后）乐于尝试此类轻户外活动，其中36%的00后和27%的95后积极参与 ^[extracted]。

### 消费特征
- **高频高价**：53%的用户每周参加1-3次轻量化运动，倾向于选择心态轻松、装备简单、能说走就走的活动 ^[extracted]。
- **消费金额**：26%的用户单次消费金额在1000-1500元之间 ^[extracted]。
- **趋势好物**：关联消费品类包括跑步鞋（如Nike Winflo 11）、多功能露营车、精油香氛沐浴露等 ^[extracted]。
