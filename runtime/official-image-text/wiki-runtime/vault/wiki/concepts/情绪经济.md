# 情绪经济

**情绪经济**是一种以满足消费者情绪价值为核心的经济形态。在2024年消费市场不确定性提升的背景下，情感已成为驱动消费的关键因素 ^[extracted]。

### 核心特征
- **驱动因素**：消费者成为消费行为的中心，情感需求取代单纯的功能需求成为决策关键 ^[extracted]。
- **关键要素**：自我表达和自我满足是情绪满足的两个关键维度 ^[extracted]。
  - **自我表达**：包括成就感、认同感、情感表达、压力释放等 ^[extracted]。
  - **自我满足**：包括满足感、幸福感、情绪纾解、充实感、个性彰显、心灵对话等 ^[extracted]。

### 视觉化表现与场景落地
情绪经济不仅停留在理论层面，更通过具体的视觉符号和生活场景进行表达：
- **场景叙事**：在空气循环扇等产品的营销中，通过展示佩戴蕾丝头巾、身穿Nike球衣的年轻女性形象，以及摆放鲜花、写有“Romantic”字样的家居角落，构建出“给情绪做套SPA”的氛围 ^[extracted]。
- **符号象征**：简单的闪光符号（如黑色四角星）与高阅读量的话题标签（#沉浸式护肤、#生活需要仪式感）结合，强化了情绪价值的可感知性与社交传播力 ^[extracted]。

### 相关概念
- [[人感优先标准]]：情绪经济背景下催生的新消费评判标准。
- [[仪式感]]：情绪经济中重要的自我满足维度。
- [[618电商大促]]：2024年618期间，情绪经济特征显著，品牌通过场景化营销满足用户情绪价值。
