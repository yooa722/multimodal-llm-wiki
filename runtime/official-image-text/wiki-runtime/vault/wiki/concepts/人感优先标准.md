# 人感优先标准

**人感优先标准**是2024年消费市场涌现的新消费价值判断标准。该标准强调消费行为以人为本，将情感置于消费决策的首位，使情绪价值的满足成为衡量商品或服务质量的关键依据 ^[extracted]。

### 构成指数
该标准由小红书与克劳锐联合推出，综合站内互动、电商平台数据及消费者调研，提炼出四个维度的“眼光指数” ^[inferred]：

1. **审美眼光指数**：代表消费者的审美价值，具体表现为小红书站内品类热点话题的点赞、收藏、评论等互动量（话题热度） ^[extracted]。
2. **投资眼光指数**：代表消费后消费者对商品价值的判断，具体表现为商品好评度和商品销量（商品消费反馈） ^[extracted]。
3. **发展眼光指数**：代表消费需求被满足的程度和消费行为的社交价值，包括消费者的消费意愿、消费水平与消费后的满意度（评价与反馈的社交感） ^[extracted]。
4. **经济眼光指数**：代表消费者对商品的综合评价，包括对商品价值及使用价值的评价（种草与价值的获得感） ^[extracted]。

### 应用场景与视觉实证
该标准应用于[[618电商大促]]期间的“好眼光指南”，旨在为消费者提供“买对”的建议，助力品牌在促销活动中有效种草 ^[extracted]。

在**空气循环扇**等具体商品场景中，人感优先标准通过视觉叙事将抽象概念具象化：
- **生活方式具象化**：图像证据展示了年轻女性的日常穿搭（如Nike球衣、蕾丝头巾）与生活状态，以及花艺陈列等场景，配合文案“Rua Rua自己，给情绪做套SPA”，将情绪价值转化为可感知的生活细节 ^[extracted]。
- **量化佐证**：相关话题标签如 #沉浸式护肤（20亿+阅读量）、#生活需要仪式感（17亿+阅读量）出现在视觉素材中，为“人感”提供了数据层面的支撑 ^[extracted]。
