# 蕉下

**蕉下**是户外服装及防晒用品领域的知名品牌。2023年618期间，其市场销售额同比增长648.78% ^[extracted]。

## 营销策略：[[货架场域经营]]

蕉下采取了“自播为主、品牌商城运营为辅”的策略，并重点深耕货架场域 ^[extracted]。

*   **销售构成**：58.39%的销售额来自于品牌自播，26.19%来自于KOL直播，14.45%为自然销售额 ^[extracted]。
*   **搜索优化**：品牌有意预埋下拉搜索词，如“户外防晒”、“夏日防晒”、“防晒衣”。证据显示，用户搜索这些关键词时，首页均能展示“蕉下防晒衣”相关商品，且价格区间覆盖广泛（如¥9.9起的袖套至¥99起的防晒衣） ^[inferred]（来源：图片 `item-p0046-b0002`, `item-p0046-b0003`, `item-p0046-b0004`）。
*   **转化路径**：通过优化搜索结果页，品牌有意引导用户点击商品后进入“蕉下官方旗舰店”直播间或旗舰店页面，形成从搜索到直播/店铺的闭环 ^[inferred]（来源：图片 `item-p0046-b0005`）。
*   **商城资源位**：充分利用抖音商城的首页推荐、618超级购、品牌馆、抖音旗舰好店等资源位，获取曝光 ^[extracted]。
*   **明星势能**：利用品牌代言人营销势能，在直播间上架“周杰伦演唱会门票”道具组件及抽奖链接，引导粉丝转化 ^[extracted]。

## 产品与达人

*   **爆品**：户外防晒衣是蕉下的核心爆品，因品牌知名度高、价格适中，用户决策成本低，容易接受KOL推荐 ^[extracted]。
*   **KOL合作**：侧重在周末/关键节点联合头腰部、偏女粉多的KOL（如巴图&博谷、柴碧云、方琼）进行带货 ^[extracted]。
