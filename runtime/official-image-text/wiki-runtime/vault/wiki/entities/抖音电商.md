# 抖音电商

**抖音电商**是[[抖音]]平台内的电子商务业务板块。在2023年618好物节期间，其表现出强劲的增长势头。

## 2023年618表现

*   **GMV增长**：抖音商城支付GMV同比增长70% ^[extracted]。
*   **规模扩张**：动销商品数同比提升57%，参与品牌数超14.3万个 ^[extracted]。
*   **销售结构**：直播带货销售额占比81.39%，自然销售额（货架场）占比15.11%，视频带货占比3.50% ^[extracted]。

## 平台策略

抖音电商正逐步从单一的直播驱动向“直播+货架”双轮驱动转型。数据显示，自然销售规模稳定增长，表明品牌的商城店铺销售渠道正在保持稳定的增长趋势 ^[extracted]。平台通过优化搜索、商城推荐位等资源位，引导用户进入品牌旗舰店完成转化，即“货架场域经营” ^[extracted]。
