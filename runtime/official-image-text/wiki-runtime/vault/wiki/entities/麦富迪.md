# 麦富迪

**麦富迪**（Myfoodie）是宠物食品行业的头部品牌。2023年618期间，其市场销售额同比增长67.09% ^[extracted]。

## 营销策略：[[社媒营销种草]]

麦富迪采取了“社媒种草+官方直播间转化”的组合策略 ^[extracted]。

*   **销售构成**：47.80%来自于直播带货（其中37.35%为品牌自播，10.45%为KOL直播），45.67%为自然销售额 ^[extracted]。较高的自然销售占比反映了种草带来的长效搜索和复购效应。
*   **跨平台种草**：
    *   **抖音**：围绕“猫狗主粮”、“营养全面”关键词投放商业作品，打造#有猫有狗就有麦富迪#话题（播放量1.5亿+） ^[extracted]。
    *   **小红书**：围绕“猫主粮”、“618囤货”关键词投放笔记，打造#麦富迪618囤货攻略#话题 ^[extracted]。
*   **达人选择**：在两个平台均以垂类宠物达人为主，精准覆盖宠物消费人群 ^[extracted]。

## 产品表现

麦富迪在宠物市场销售额TOP10品牌中位居第一，份额占比5.43% ^[extracted]。其旗下猫粮产品最为热销，多个SKU上榜 ^[extracted]。
