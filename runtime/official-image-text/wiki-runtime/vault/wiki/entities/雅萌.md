# 雅萌

**雅萌**（YAMAN）是美容仪器赛道的领先品牌。2023年618期间，其市场销售额同比增长118.92% ^[extracted]。

## 营销策略：[[KOL带货合作]]

雅萌在大促期间采取了深度合作头部KOL渠道进行带货直播的策略 ^[extracted]。

*   **销售构成**：84.24%的销售额来自于KOL直播，仅8.99%来自于品牌自播 ^[extracted]。
*   **核心达人**：直播带货增长主要来源于头部达人“金爱罗”，其单场直播带货GMV指数高达11772，预估销售指数为11816，均为品牌最高 ^[extracted]（来源：表格 `item-p0040-b0002`，图表 `item-p0039-b0014`）。其他重要合作达人包括东方甄选美丽生活（GMV指数4156）、千惠在这里（GMV指数3431）等 ^[extracted]。
*   **爆发节点**：品牌直播爆发集中在预售期、周末及BigDay等关键时间点 ^[extracted]。

## 爆品策略

雅萌通过强竞争力的高客单明星商品实现增长 ^[extracted]：
*   **黄金五环家用美容仪提拉紧致ACE五代T**：主打五环射频技术，销售指数为7803，位列美妆品牌618期间销售额TOP10商品榜第5名 ^[extracted]（来源：表格 `item-p0041-b0002`）。商品主图标注“45年突破 雅萌王牌射频”及“ACE五代｜黄金五环射频仪” ^[extracted]（来源：图片 `item-p0041-b0004`）。
*   **雅萌MAX二代家用美容射频仪器MAX二代T**：主打5大SPA模式，销售指数为5351，位列榜单第9名 ^[extracted]。商品主图显示售价为¥5799，并标注“享直播好礼1立即抢购” ^[extracted]（来源：图片 `item-p0041-b0007`）。

这两款高客单美容仪器在618期间备受追捧，均有SKU上榜美妆市场销售额TOP10商品榜单 ^[extracted]。
