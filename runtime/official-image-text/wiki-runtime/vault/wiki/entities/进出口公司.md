# 进出口公司

[[进出口公司]]是集团ERP实施范围内的业务单元之一，主要承担销售职能 [104页-ERP财务供应链解决方案@386617a95792#item-p0007-b0003]。

该公司涉及特殊的[[直运销售]]业务，即为减少仓储物流成本并快速响应客户交货时间，要求供应商将商品直接发往客户。在此模式下，采购入库和销售出库均为虚拟单据，无实物出入库 [104页-ERP财务供应链解决方案@386617a95792#item-p0022-b0004]。业务管控要求在实际作业过程中必须先审核采购发票后审核销售发票 [104页-ERP财务供应链解决方案@386617a95792#item-p0023-b0003]。
