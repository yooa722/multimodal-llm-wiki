# 磁材公司

[[磁材公司]]是集团ERP实施范围内的主要业务单元之一，具备法人、行政、销售、财务、资产、库存、采购、质检等完整组织职能 [104页-ERP财务供应链解决方案@386617a95792#item-p0007-b0003]。

在业务流程中，[[环磁分厂]]（隶属于磁材业务板块）的产成品集中由本部进行销售。通过[[调拨订单]]，从环磁仓库调拨至本部仓库，再由本部录入销售出库单 [104页-ERP财务供应链解决方案@386617a95792#item-p0020-b0003]。其原材料和配方料的采购也遵循统一的质检入库流程 [104页-ERP财务供应链解决方案@386617a95792#item-p0035-b0009]。
