# 奥维云网

**奥维云网**（All View Cloud，简称 AVC）是一家专注于垂直领域的大数据应用技术和解决方案服务商，证券代码为 831101 ^[extracted]。

该公司以开放式大数据平台为核心资源，整合全产业链数据体系，具备从数据采集处理、存储计算、挖掘分析、可视化和应用等核心环节的大数据技术能力 ^[extracted]。其主要业务面向零售交易大数据、家庭互联网用户大数据、企业大数据、金融大数据、酒店及旅游大数据等领域，为企业提供“数据＋技术＋服务”的全方位大数据解决方案 ^[extracted]。

在[[冰洗市场]]研究中，奥维云网定期发布市场小结及促销期预测，如《2023年开年冰洗小结及五一、618预测》 ^[extracted]。此外，奥维云网厨卫事业部也持续跟踪厨卫刚需品类表现，发布了《2023年618厨卫刚需品类市场总结》，深入分析了油烟机、燃气灶、电热水器和燃气热水器在促销期间的线上市场表现、结构升级及消费趋势 ^[extracted]。
